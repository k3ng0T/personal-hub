Univigate ↗

Messenger-app ↗

Python / PySide6 / SQL

A local network messenger with a clean, modern UI. Users can join the same localhost/LAN network, send messages in real time, and chat with a polished, responsive interface.

A web application for automating WhatsApp messages. Users can schedule a message to a specific number at a chosen time, set the number of messages to send, and control the delay (cooldown) between each one.
